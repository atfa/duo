◆ XDUO / REMOTE ACCESS

Your computer.
Your remote workspace.

Use xduo from another device while Duo and its agents keep running on your computer.

This is a setup guide, not a shared tunnel service. Downloading duo + xduo does not register your computer with desktop.xduo.dev. That hostname connects to the maintainer's configured machine. To use the Tunnel button, configure a hostname and tunnel that you own. Never copy or distribute another computer's tunnel credentials.

01 / NO TUNNEL NEEDED ON YOUR LAN

Connect on the same network

Enable Server in xduo. On another device, open the LAN address displayed beside Server and enter the room code. Direct access to http://127.0.0.1:8787/ on the host computer is passwordless.

02 / CHOOSE YOUR OWN PUBLIC ENTRY

Create a named Cloudflare Tunnel

Install cloudflared and sign in to the Cloudflare account managing your domain. During login, select your own domain. Create a named tunnel and route a hostname such as desktop.example.com to it.

cloudflared tunnel login
cloudflared --config /dev/null tunnel create xduo-desktop
cloudflared --config /dev/null tunnel route dns YOUR_TUNNEL_ID desktop.example.com

The commands above are for Linux, xduo's supported tmux platform. Record the Tunnel ID and the absolute path of the credentials JSON file generated by cloudflared. Keep that file on this computer.

03 / CONNECT XDUO

Add your local configuration

Create ~/.duo/xduo/tunnel.json:

{
  "hostname": "desktop.example.com",
  "tunnel": "YOUR_TUNNEL_ID",
  "credentialsFile": "/absolute/path/to/YOUR_TUNNEL_ID.json"
}

Click Tunnel in xduo. A loading panel opens immediately, then displays your remote link and room code when connected. Use Copy room code to copy its eight characters. Both ABCD-E7K9 and ABCDE7K9 are accepted at login.

04 / CONTROL HANDOFF

One active operator

When the browser connects, the local terminal locks and shows STOP SERVER. Click that button or press Enter to disconnect the browser and restore local control. Closing a browser tab leaves Duo running.

You may also use a tunnel or reverse proxy of your choice, forwarding HTTP and WebSocket traffic to the xduo Server. Preserve the original Host header so remote login and WebSockets work correctly. TLS is handled by your proxy or tunnel.

This page configures no account, collects no credentials, and never receives your room code.
