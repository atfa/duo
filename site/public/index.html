What is Duo?

You bring the agents. Duo helps them work together.

Duo is not an agent and does not provide a model. Install and configure at least one of pi, opencode, codex or agy first. The two agents can use the same or different tools and models.

Duo spends more time and tokens in pursuit of a better result through discussion and mutual review. You still decide whether the result is good enough.

Three modes

Choose how to work together.

FAST

Get started directly

One agent implements and the other verifies, for well-defined tasks.

GOAL

Agree on a plan

Both agents agree on a plan, work independently and review each other, for complex tasks.

STEP

Work step by step

Both agents agree on an ordered list and implement and verify each step, for longer tasks.

Phone and browser

Duo runs on your computer. Control it from elsewhere.

01 / DUO REMOTE

Control a Duo from your phone

Enter /qrcode in Duo and scan it to pair your phone. Check status, submit tasks, pause or continue, and change the mode, agent or model.

02 / XDUO

Run multiple Duo sessions

xduo is a session manager: create, open, resume and switch between multiple Duo instances. Each instance has its own session and phone pairing.

03 / BROWSER

Use xduo in a browser

Click Server in xduo and open the displayed address locally. Other devices can use the LAN address and room code. When a browser connects, the local terminal locks; click STOP SERVER to regain control.

04 / TUNNEL

Access it remotely through a tunnel

Choose your own tunnel or reverse proxy. The Tunnel button supports a configured Cloudflare Tunnel and requires your own domain and credentials; see the setup guide. desktop.xduo.dev is not an automatically shared endpoint for all users.

Install and use

Install it, then start working.

01

Prepare an agent

Install and configure pi, opencode, codex or agy, and install Git.

02

Install Duo and xduo

On macOS or Linux, run:

curl -fsSL https://raw.githubusercontent.com/atfa/duo/main/scripts/install-release.sh | bash

For Windows, see the README.

03

Run Duo

Enter your project directory, run duo, and describe your task. First run guides you through the required setup.

cd /path/to/project duo
04

Manage sessions with xduo

On Linux, install tmux 3.2 or newer, run xduo, and select [+] to create a workspace. Click Server for browser access; configure a tunnel for remote access.
