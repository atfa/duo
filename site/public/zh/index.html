Duo 是什么

你提供 Agent，Duo 组织协作。

Duo 本身不是一个 Agent，也不提供模型。你需要事先安装并配置好 pi、opencode、codex 或 agy 中至少一个。两个 Agent 可以使用相同或不同的工具与模型。

Duo 会花费更多时间和 token，目标是通过协商与相互审查交付更好的结果；结果仍需要你自己判断。

三种工作模式

按任务选择协作方式。

FAST

直接开始

一方实现，另一方验证，适合边界清晰的任务。

GOAL

先商量，再动手

双方共同确定计划，独立工作并交叉审查，适合复杂任务。

STEP

一步一步完成

双方商定有序步骤，逐步实现与验证，适合较长的任务。

手机与浏览器

Duo 在你的电脑上运行，你可以从别处控制。

01 / DUO REMOTE

在手机上控制一个 Duo

在 Duo 中输入 /qrcode，用手机扫码配对。你可以查看状态、提交任务、暂停或继续，以及切换模式、Agent 和模型。

02 / XDUO

同时运行多个 Duo

xduo 是会话管理器：创建、打开和恢复多个 Duo，在它们之间切换。每个 Duo 都有自己的会话和手机配对。

03 / BROWSER

在浏览器中使用 xduo

点击 xduo 的 Server，在本机浏览器打开显示的地址；另一台设备可使用局域网地址和房间号。浏览器连接后，本地终端会锁定，点击 STOP SERVER 可恢复。

04 / TUNNEL

通过隧道远程访问

你可以自行选择隧道或反向代理。xduo 的 Tunnel 按钮支持已配置的 Cloudflare Tunnel；使用它需要自己的域名和凭据，查看配置指南。desktop.xduo.dev 不是为所有用户自动提供的共享入口。

安装与使用

先安装，再开始。

01

准备 Agent

先安装并配置 pi、opencode、codex 或 agy，以及 Git。

02

安装 Duo 和 xduo

在 macOS 或 Linux 上运行：

curl -fsSL https://raw.githubusercontent.com/atfa/duo/main/scripts/install-release.sh | bash

Windows 安装方法请查看 README。

03

运行 Duo

进入项目目录，运行 duo，然后输入任务。首次运行会引导你完成必要的配置。

cd /path/to/project duo
04

使用 xduo 管理多个会话

在 Linux 上安装 tmux 3.2 或更新版本，运行 xduo，选择 [+] 创建工作区。点击 Server 开启浏览器访问；需要远程访问时配置隧道。
